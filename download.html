Verify before running

Download the SHA-256 checksum file, then compare its digest with:

Get-FileHash .\ARFastSNTP-Setup-Windows-x64.exe -Algorithm SHA256

Use all releases for version history. Each GitHub Release records its verified source commit, installer, and checksum.

Before installing

  • Test PC only. No live SCADA, SOE or historian deployments.
  • Provide a reachable IPv4 unicast NTP server on UDP port 123.
  • Clock correction is enabled by normal setup. For monitor-only testing, launch with /LABSYNC=0.
  • SmartScreen may warn about this unsigned release. Check the GitHub source and SHA-256; never disable security protections solely to install.
  • To uninstall, use Windows Settings → Installed apps → AR Fast SNTP.
