Verify before running

Download the SHA-256 checksum file, then compare its digest with:

Get-FileHash .\ARFastSNTP-Setup-Windows-x64.exe -Algorithm SHA256

Use all releases for version history. Each GitHub Release records its verified source commit, installer, and checksum.

Quick start

  1. Download the Windows installer and run it as administrator.
  2. Enter your GPS/NTP server IPv4 address during setup.
  3. Open AR Fast SNTP and watch your clock synchronization status.

Linux x64 beta: Download Linux and follow the quick setup guide.

Use a PC where you are authorized to change system time. The Windows installer is currently unsigned; verify the official GitHub release and checksum. Installation help.
