AR FAST SNTP — QUICK START
===========================

Primary goal: INSTALL → SYNC → MONITOR.

1. Download the latest GREEN ARFastSNTP-Windows-x64 GitHub Actions artifact.
2. Extract entire ZIP.
3. Open dashboard\ARFastSNTP.Dashboard.exe.
4. Set SERVER IP and reference YEAR.
5. On your authorized, isolated test PC, click INSTALL & SYNC and approve UAC.
6. Setup automatically installs OR UPDATES the existing ARFastSNTP service.
   No REMOVE SERVICE, mode picker, repeated confirmation, or PowerShell required.
7. Check setup reports service RUNNING in LAB CLOCK CORRECTION mode.
8. View server UTC, PC UTC, offset, RTT and correction events in dashboard.
9. If state remains OFFSET, inspect worker status and correction events;
   RUNNING alone does not prove time adjustment succeeded.

IMPORTANT:
- CONNECT is *diagnostic monitoring only* and does not set Windows time.
- An existing Monitor Only service will be upgraded in-place.
- Other time-setting services may conflict; setup warns but does not stop them.
- Only use forced time correction on an approved isolated certification PC.
- Installer errors: C:\ProgramData\ARFastSNTP\setup.log

Artifact layout:
ARFastSNTP.Setup.exe       [GUI installer, sync by default]
install-sync.cmd           [convenience shortcut]
install-monitor.cmd        [optional monitor-only diagnostic]
uninstall.cmd
worker\ARFastSNTP.exe
dashboard\ARFastSNTP.Dashboard.exe
