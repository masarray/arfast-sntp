AR FAST SNTP — QUICK START
==========================

WINDOWS
1. Download the latest stable Windows installer:
   https://github.com/masarray/arfast-sntp/releases/latest
2. Run setup and enter your SNTP/NTP server IPv4 address.
3. Open AR Fast SNTP from the Start menu and check sync status.

LINUX
Download the Linux x64 beta and follow docs/LINUX-INSTALL.md:
https://github.com/masarray/arfast-sntp/releases/tag/linux-v0.1.0-beta.1

Beginner-friendly guide:
https://github.com/masarray/arfast-sntp/blob/main/docs/QUICK-START.md

Full project website: https://masarray.github.io/arfast-sntp/
