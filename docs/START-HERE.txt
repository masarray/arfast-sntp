AR Fast SNTP — Windows setup v0.9.1 candidate
===============================================

1. Get the latest successful ARFastSNTP-Inno-Windows-x64 GitHub Actions artifact.
2. Extract its ZIP; run ARFastSNTP-Setup-Windows-x64.exe.
3. Enter your trusted NTP server IPv4, select Next and finish setup.
4. Existing PowerShell/WinForms/Inno service configurations are recognized
   by the same canonical ARFastSNTP Windows Service name.
5. One service runs in the background. Closing Avalonia Studio does NOT stop it.

Studio main view: PC Time, PC Sync Status, NTP Server table, collapsed History.
No duplicate Install button; NTP era reference year is an advanced installer
argument rather than a normal setup field.

On an installation failure, see
C:\ProgramData\ARFastSNTP\setup.log
and preserve the installer-recovery folder if present.

Only approved isolated test PCs may use system-clock stepping.
Do not remove or overwrite another vendor's service to make setup succeed.
The current worker supports one NTP source; multi-peer is a future milestone.
