AR Fast SNTP - QUICK START / TROUBLESHOOTING
===========================================

1. Download latest GREEN GitHub Windows Actions artifact ARFastSNTP-Windows-x64.
2. Extract ALL files to a new folder. Do not mix old worker/dashboard binaries.
3. Launch dashboard\ARFastSNTP.Dashboard.exe.
4. Enter SNTP Server IP, YEAR (2026), click CONNECT.
5. ONLINE + VALID means actual NTP UDP/123 request/reply. An offset of about
   1,018,249,956,697 milliseconds is about 32 YEARS and is not automatically corrected
   in portable MONITOR ONLY mode.
6. To run at Windows startup, click INSTALL SERVICE.
7. The NEW installer ARFastSNTP.Setup.exe is graphical and NEVER runs PowerShell.
   It retains errors on screen, plus %ProgramData%\ARFastSNTP\setup.log.
8. For time correction, only on an isolated certification PC, choose LAB CLOCK STEP,
   check the explicit risk acknowledgment, and use Administrator approval. Never
   use it on a production SCADA/SOE/historian PC.
9. If install reports W32Time/NTP/Meinberg conflict, resolve existing time services
   with an authorized administrator: this app does not stop them silently.
10. If setup reports ARFastSNTP service already exists, choose REMOVE SERVICE
    and then INSTALL SERVICE to change the server/step mode. Save logs first.

Installation package root:
- ARFastSNTP.Setup.exe      <-- NEW graphical installer (not PowerShell)
- install-monitor.cmd
- install-certification-lab.cmd
- uninstall.cmd
- worker\ARFastSNTP.exe
- dashboard\ARFastSNTP.Dashboard.exe

A background service must remain RUNNING after setup. Dashboard may be closed
without terminating it. Portable CONNECT mode stops on GUI close.
