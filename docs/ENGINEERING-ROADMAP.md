# Engineering roadmap

AR Fast SNTP is designed to make time synchronization straightforward for engineering PCs. The public Windows release is ready for supported laboratory and learning workflows.

These are **optional future quality milestones**, maintained separately from the stable release checklist:

- Publisher code signing and Windows download reputation.
- More upgrade, rollback and uninstall test combinations.
- Extended-running CPU/memory/socket checks, reboot, sleep/resume and repeated network interruptions.
- Additional Windows desktop DPI and accessibility coverage.
- Larger clock-change scenarios, source conflicts and independent reference checks.
- Raw-packet test server interoperability across isolated hosts.
- Linux beta follow-up: installed service, clock correction, desktop permissions and reconnect testing on a physical PC or disposable VM.

Current stable releases are published from validated source and include SHA-256 files. For support, see [SUPPORT.md](../SUPPORT.md); for responsible use and reporting, see [SECURITY.md](../SECURITY.md).
